# Style & UI Rules

이 문서는 프로젝트 내 스타일 구성 및 UI 구현 규칙을 정의합니다.

## 1. Tailwind CSS v4 (기본 표준)
이 프로젝트는 **Tailwind CSS v4**를 사용하여 모든 UI를 구현합니다. 
- **Utility-first**: 가능한 모든 스타일은 Tailwind 클래스를 통해 작성합니다.
- **인라인 스타일 지양**: 가변적인 값(예: 계산된 위치 등)을 제외하고는 인라인 스타일을 사용하지 않습니다.
- **가독성 관리**: 클래스가 너무 길어질 경우, 논리적 단위로 줄바꿈을 하거나 필요한 경우 `@theme` 변수를 활용합니다.

## 2. 디자인 토큰 및 테마 (src/styles/style.css)
- 전역 색상, 간격, 폰트 크기 등은 `src/styles/style.css`의 `@theme` 블록에서 정의된 변수를 사용합니다.
- 예: `text-primary`, `bg-bg`, `p-lg` 등 커스텀 유틸리티를 적극 활용하십시오.

## 3. 클래스 네이밍 (Legacy & Exceptions)
- 기본적으로 BEM 네이밍은 더 이상 사용하지 않습니다.
- 다만, 외부 라이브러리 커스텀이나 복잡한 애니메이션을 위해 순수 CSS가 필요한 경우에만 예외적으로 의미 있는 클래스명을 사용합니다.

## 4. 리소스 처리
- 아이콘이나 이미지는 가능한 SVG 또는 `src/assets/` 리소스를 활용합니다.
- 아이콘은 전용 `Icon` 컴포넌트를 통해 사용하며, `src/types/icon-types.ts`의 타입을 준수해야 합니다.
- 동적 이미지는 `base64` 인코딩을 지양하고 파일 경로를 활용합니다.
